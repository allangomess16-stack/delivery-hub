# V0.2.7 — Acesso pela rede local

## Problema corrigido

O servidor já escutava em `0.0.0.0`, porém dois fatores podiam impedir o celular:

1. o primeiro IPv4 encontrado podia pertencer a VPN, WSL, Hyper-V ou adaptador virtual;
2. o Firewall do Windows podia bloquear conexões de entrada na porta 5173.

## Alterações

### IP

O servidor agora:

- prioriza o IP obtido pela rota padrão do Windows;
- prioriza faixas LAN privadas (`192.168.*`, `10.*`, `172.16-31.*`);
- reduz prioridade de WSL, Hyper-V, VMware, VirtualBox, VPN etc.;
- mostra todos os endereços candidatos quando houver mais de um.

### Firewall

`BAT\04_CORRIGIR_ACESSO_CELULAR.bat` cria:

```text
Delivery Hub - Porta 5173
TCP 5173
Entrada
Somente perfil Private
```

Ele solicita elevação do Windows por UAC.

### Diagnóstico

`BAT\04_CORRIGIR_ACESSO_CELULAR.bat` verifica:

- IPv4;
- porta 5173 em LISTENING;
- `/api/health` via localhost;
- `/api/health` via IP LAN;
- regra de Firewall;
- categoria Private/Public da rede.

## Teste

1. Execute `BAT\01_SERVIDOR_LOCAL.bat` e mantenha aberto.
2. Se o celular não abrir, em outra janela execute `CORRIGIR_ACESSO_CELULAR.bat`.
3. No celular, teste o endereço recomendado e, se houver, os outros endereços LAN exibidos.

PC e celular precisam estar na mesma rede local e redes de convidados podem impedir comunicação entre dispositivos.
