# V0.2.9 — Organização dos arquivos

## Objetivo

Eliminar o acúmulo de BATs de cada release e manter apenas os comandos necessários para o estágio atual.

## Antes

A raiz carregava arquivos como:

```text
TESTAR_V021.bat
TESTAR_V022.bat
TESTAR_V023.bat
...
VALIDAR_V021.bat
VALIDAR_V022.bat
...
```

além de atalhos e scripts Windows duplicados.

## Agora

Existe apenas a pasta:

```text
BAT/
```

com cinco comandos permanentes.

Nenhum `.bat` fica na raiz e `scripts/windows/` foi removido. Os BATs atuais calculam a raiz do projeto usando `BAT\..`, portanto continuam funcionando com caminhos relativos e sem depender do local em que o projeto foi extraído.

## Política para próximas versões

- não criar BAT com número da versão;
- substituir o BAT permanente quando houver correção;
- adicionar um novo BAT somente quando existir uma nova tarefa recorrente real;
- manter comandos de uso diário em `BAT/`;
- manter lógica Node em `scripts/node/`;
- documentação antiga vai para `docs/historico/`, sem poluir a documentação atual.
