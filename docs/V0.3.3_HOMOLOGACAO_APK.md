# V0.3.3 — APK de homologação

## Público

Sócio, avaliador e posteriormente o entregador.

Não exige conta real.

## Funções

### Carga demonstrativa

Exibe uma operação fictícia para avaliar:

- design;
- quantidade de informação;
- tamanho de botões;
- regionalização visual;
- sequência de telas;
- fotos;
- recebedor;
- confirmação.

### Scan real / somente leitura

Uma etiqueta real pode ser fotografada.

O sistema tenta:

```text
FOTO
↓
barcode / QR
↓
normalização
↓
tracking
↓
regra de transportadora
↓
informação disponível
```

Pode mostrar:

- tracking;
- J&T / Anjun / iMile / desconhecida;
- confiança;
- regra usada;
- package operacional já conhecido no projeto;
- nível atual da integração.

### Limite proposital

A leitura real NÃO:

- consulta destinatário;
- descobre endereço em servidor externo;
- registra pacote em carga oficial;
- envia foto para transportadora;
- confirma entrega;
- altera status em Anjun/iMile/J&T.

Depois do scan é possível usar o tracking apenas dentro de uma **simulação local**
para avaliar a experiência do fluxo.

## Build

```text
BAT/APK/01_GERAR_APK_HOMOLOGACAO.bat
```

O script:

1. instala dependências;
2. localiza/prepara JDK;
3. localiza/prepara Android SDK;
4. habilita temporariamente `homologacao-config.json`;
5. executa validação e testes;
6. cria/sincroniza Capacitor Android;
7. compila `assembleDebug`;
8. copia o APK para:

```text
APK/DeliveryHub-Homologacao-v0.3.3.apk
```

O modo normal é restaurado depois do build.

## Build pelo GitHub

Depois que o repositório estiver configurado e a versão estiver em `main`:

```text
BAT/GITHUB/07_GERAR_APK_HOMOLOGACAO.bat
```

O BAT:

1. dispara `.github/workflows/apk-homologacao.yml`;
2. acompanha a compilação;
3. interrompe se os testes falharem;
4. baixa o artefato final;
5. abre a pasta `APK/`.

Esse caminho não exige Android Studio nem SDK Android instalados localmente.
