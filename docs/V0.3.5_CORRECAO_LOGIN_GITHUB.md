# V0.3.5 — Correção de login GitHub no Windows

Sintoma observado:

```text
[ERRO] A autenticacao ainda nao respondeu pela API do GitHub.

github.com
✓ Logged in to github.com account ...
Active account: true
```

Nesse cenário o login já estava correto.

O problema estava no BAT ao executar `gh api user` dentro de `FOR /F` quando
`gh.exe` podia estar referenciado por caminho com espaços.

A V0.3.5:

- considera `gh auth status` como confirmação suficiente;
- executa comandos `gh ...` diretamente e grava o retorno em arquivo temporário;
- lê o arquivo depois, evitando problemas de quoting do `cmd.exe`;
- aplica a mesma correção à identificação do repositório e do workflow;
- não grava token/senha no projeto.
