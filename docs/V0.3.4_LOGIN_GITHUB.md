# V0.3.4 — Login GitHub CLI

A conexão GitHub disponível dentro do ChatGPT é independente da GitHub CLI
instalada no Windows.

Para autenticar o computador:

```text
BAT/GITHUB/00_LOGIN_GITHUB.bat
```

O BAT executa:

```text
gh auth status
↓
gh auth login --web
↓
gh auth setup-git
↓
gh api user
```

Se o GitHub mostrar um código temporário, copie o código e autorize a GitHub CLI
na página que abrir no navegador.

Nenhum token ou senha fica salvo no código-fonte ou nos BATs.
