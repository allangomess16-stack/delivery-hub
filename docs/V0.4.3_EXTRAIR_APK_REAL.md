# V0.4.3 — extração do APK real instalado

Esta versão corrige o BAT de extração Android.

## Problema encontrado

O `04_EXTRAIR_APK_INSTALADO.bat` ainda executava `adb.exe` diretamente dentro
de `FOR /F`. Em caminhos longos do Windows isso gerava:

```text
A sintaxe do nome do arquivo, do nome do diretório ou do rótulo do volume está incorreta.
```

O Android e a iMile não eram o problema.

## Correção

O BAT agora:

1. executa `adb devices` fora de qualquer `FOR /F`;
2. salva a saída em arquivo temporário;
3. interpreta o arquivo;
4. executa `pm path` fora de qualquer `FOR /F`;
5. salva todos os caminhos `package:`;
6. copia **base.apk e todos os split APKs** instalados;
7. registra `versionName`, `versionCode`, launcher e SHA-256;
8. cria um ZIP pronto para análise.

Para iMile, execute:

```text
BAT\ANDROID\04_EXTRAIR_APK_INSTALADO.bat
```

e escolha `2 - iMile`.

O resultado esperado fica em:

```text
diagnosticos-apk\IMILE_<versao>_<versionCode>_APKS.zip
```

## SDK

A descoberta do ADB também passou a procurar a estrutura:

```text
Downloads\
  DeliveryHub-V0.x.x-COMPLETO\
    delivery-hub-v0.x.x\
      .ferramentas\android-sdk\
```

Assim uma versão nova pode reutilizar o SDK já baixado em outra versão extraída
no mesmo diretório geral.
