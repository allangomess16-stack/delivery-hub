# V0.4.6 — NativeBridge e adaptador iMile

## Objetivo

Conectar o Delivery Hub a entrada externa comprovada da iMile sem acoplar o
dominio a Android, Capacitor ou a gramática `crredelivery:`.

## Fluxo

```text
AplicacaoHomologacao
  -> IntegracaoTransportadora
  -> IMileAdapter
  -> PonteNativa
  -> PonteNativaCapacitor
  -> NativeBridgePlugin
  -> Intent ACTION_VIEW + setPackage(com.imile.redelivery)
```

## Protecoes

- modo de homologacao aceita somente `DH_TESTE_INVALIDO`;
- operacao aceita somente trackings iMile reconhecidos pelo Delivery Hub;
- URI nativa limitada a `crredelivery:?requestCode=...`;
- pacote nativo limitado a `com.imile.redelivery`;
- versao diferente de `versionCode 458` bloqueia o adaptador;
- erros esperados retornam resultado estruturado;
- falha de registro da ponte usa `DH-NAT-S02-PONTE` e nao e confundida com app ausente;
- o retorno `DESPACHADO` nao e tratado como baixa ou pesquisa confirmada;
- nenhum tracking e escrito em log nativo.

## Android gerado

A pasta `android/` continua descartavel. Depois de `npx cap add/sync android`,
os scripts aplicam:

```text
scripts/node/aplicar-queries-android.mjs
scripts/node/aplicar-native-bridge-android.mjs
```

O segundo script copia o plugin mantido em `native/android/` e registra a
classe no `MainActivity`. O processo foi testado duas vezes seguidas sem gerar
duplicacao.

## Homologacao

No Windows:

```text
BAT\ANDROID\06_HOMOLOGAR_DEEP_LINK_IMILE.bat
```

No APK de homologacao, usar `TESTAR NAVEGACAO IMILE`. Aprovar somente se:

- abrir diretamente a iMile;
- exibir a pesquisa comum;
- preencher `DH_TESTE_INVALIDO`;
- nao alterar nenhuma entrega.

A pesquisa contextual foi promovida para `DEVICE_VALIDATED` depois da
homologacao no aparelho. `PRODUCTION_VALIDATED` exige teste operacional
separado e autorizado.

# Instalação paralela de homologação

O APK de homologação usa `com.deliveryhub.homologacao`. Esse ID é diferente do
aplicativo operacional `com.deliveryhub.app`, permitindo manter a versão de
referência instalada mesmo que tenha sido assinada em outro computador.
