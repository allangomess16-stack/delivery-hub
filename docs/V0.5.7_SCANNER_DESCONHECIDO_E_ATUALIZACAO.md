# V0.5.7 — Scanner desconhecido e atualização

## Correção do scanner ao vivo

Quando a câmera lê um código sem padrão cadastrado, o Hub agora confirma o
mesmo código em dois quadros e abre a seleção manual de iMile, J&T Express ou
Anjun. O tracking lido é preservado; após a escolha, o fluxo normal e a abertura
do aplicativo da empresa continuam iguais.

## Correção da atualização

A consulta não é mais bloqueada pela informação `navigator.onLine` do WebView
Android. Primeiro ela usa `app-update-config.json`; se este arquivo ou o destino
remoto falhar, consulta `app-update.json` diretamente no Hosting.

## Publicação e teste

O fluxo de publicação agora verifica o Git local automaticamente. Se a pasta
ainda não tiver `.git`, `03_PUBLICAR_VERSAO.bat` chama a configuração inicial;
não é necessário lembrar de uma etapa separada.

O BAT de publicação do Firebase também recria o manifesto depois da existência
do `origin`, garantindo que o endereço do APK da Release não fique vazio.

Uma Release privada não serve como canal de atualização: o Android não possui
credenciais do GitHub para baixar o arquivo. Antes do deploy, o BAT valida se o
repositório e o APK da Release estão públicos; caso contrário, ele interrompe a
publicação sem anunciar uma atualização quebrada.

O código-fonte pode ficar em outro repositório. Na primeira publicação, o BAT
08 pergunta qual é o repositório público de distribuição e grava essa escolha
em `firebase/projeto.local.env` como `UPDATE_RELEASE_REPOSITORY`.

## Repositório único

O projeto usa somente `allangomess16-stack/delivery-hub` como repositório
principal. O BAT de configuração não cria repositórios e bloqueia uma pasta
conectada a outro `origin`, prevenindo versões espalhadas em projetos paralelos.

1. Execute `BAT\PUBLICAR_PILOTO_COMPLETO.bat`.
2. Instale `APK\DeliveryHub-Piloto-Firebase-v0.5.7.apk` sobre o aplicativo atual.
3. Leia uma etiqueta sem padrão e mantenha-a enquadrada por um instante; escolha
   manualmente a empresa quando a tela aparecer.
4. Para validar a atualização automática, publique depois uma versão `0.5.8`.
   A V0.5.7 instalada deverá mostrar o aviso ao ser aberta com internet.

O aviso que a V0.5.5 não exibiu não pode receber a correção por si só: ela já
contém o código antigo. Por isso a instalação manual desta V0.5.7 é a ponte para
testar a próxima atualização automática.
