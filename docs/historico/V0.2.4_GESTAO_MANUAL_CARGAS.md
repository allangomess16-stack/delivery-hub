# V0.2.4 — Gestão Manual de Cargas

## Regra de linguagem

**Associar coluna ao perfil** não significa receber a carga de outra pessoa.

Associação é uma regra permanente de identificação:

```text
Coluna Excel "PEDRO"
→ Perfil Pedro Silva
→ ENT-PEDRO
```

Se outro entregador assumir encomendas de Pedro, a operação correta é **TRANSFERIR**.

## Funcionalidades

### Gestão de cargas no Admin

- listar cargas existentes;
- buscar tracking em todas as cargas;
- criar uma carga manual para um perfil;
- adicionar encomenda manualmente;
- identificar transportadora pelo código;
- bloquear duplicidade ativa do mesmo código no mesmo dia;
- excluir pacote ainda não iniciado;
- transferir um pacote pendente para outro entregador;
- transferir todos os pacotes pendentes para outro entregador;
- publicar carga manual;
- encerrar carga somente quando todos os pacotes estiverem finalizados.

### Estados

Cargas manuais começam como:

```text
RASCUNHO
```

e não são visíveis ao entregador.

Depois de:

```text
PUBLICAR CARGA
```

ficam disponíveis ao perfil correto.

Cargas vindas do Excel continuam sendo publicadas quando o Admin conclui a conciliação e distribuição.

## Segurança operacional

Pacotes em `PREPARANDO`, `AGUARDANDO_RECEBEDOR`, `ENTREGUE` ou `NAO_ENTREGUE`
não podem ser transferidos ou excluídos pela gestão manual.

Isso evita conflito com um entregador que já iniciou a operação.

## Excel + Admin

O Excel continua sendo recomendado para entrada em massa.

O Admin é a fonte de correção operacional durante o dia:

```text
EXCEL
→ entrada em massa

ADMIN
→ adicionar
→ excluir
→ transferir
→ buscar
→ corrigir
```
