# V0.4.4 — correção do adb pull

O Android retornou corretamente o caminho:

```text
package:/data/app/.../com.imile.redelivery.../base.apk
```

e o `pacote-info.txt` foi criado, porém o arquivo `base.apk` não foi copiado.

## Correção

O extrator agora:

- cria `diagnosticos-apk/extracao-apk-log.txt` logo no início;
- preserva toda saída de `adb devices`, `pm path` e `adb pull`;
- usa destino de arquivo explícito:
  `...\IMILE_2.3.18_458\base.apk`;
- verifica `ERRORLEVEL` imediatamente depois do `adb pull`;
- verifica fisicamente se o APK existe e registra o tamanho;
- mantém `pause` em todos os caminhos de sucesso, erro e cancelamento;
- se a compactação falhar, considera a extração parcial bem-sucedida e permite
  enviar o `base.apk` diretamente.

## Execução

```text
BAT\ANDROID\04_EXTRAIR_APK_INSTALADO.bat
```

Escolha:

```text
2 - iMile
```

Se houver erro, envie:

```text
diagnosticos-apk\extracao-apk-log.txt
```

Se funcionar, envie:

```text
diagnosticos-apk\IMILE_2.3.18_458_APKS.zip
```

ou diretamente:

```text
diagnosticos-apk\IMILE_2.3.18_458\base.apk
```
