# Glossário

**Delivery Hub** — aplicativo central do entregador.

**DeliveryProof** — prova universal capturada pelo Hub.

**POD** — Proof of Delivery.

**Estado físico** — situação real da encomenda.

**Estado sistêmico** — situação no sistema externo da transportadora.

**Adapter** — módulo que traduz o modelo interno para uma transportadora.

**NativeBridge** — contrato que isola recursos Android.

**IntegrationRegistry** — catálogo versionado das capacidades conhecidas.

**CapabilityEvidence** — nível de comprovação de uma capacidade.

**Fallback** — mecanismo alternativo usado quando a integração preferencial falha.
