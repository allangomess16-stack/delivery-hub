# Changelog de Arquitetura

## 2026-08-27 — Dia 0

### Decisões

- Hub multitransportadora definido;
- foco: eliminar retrabalho do fim do dia;
- J&T, Anjun e iMile como casos iniciais;
- PWA puro descartado como arquitetura principal;
- wrapper Android/native bridge adotado;
- DeliveryProof universal;
- estado físico separado do estado sistêmico;
- IntegrationRegistry versionado;
- CapabilityEvidence adotado;
- fallback automático por versão;
- FileProvider/content URI como padrão de compartilhamento;
- Package Visibility incorporada ao NativeBridge;
- Discovery Data separado do Registry;
- AccessibilityService mantido como último recurso.
