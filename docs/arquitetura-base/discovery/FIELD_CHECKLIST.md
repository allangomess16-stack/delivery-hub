# Checklist de Campo

## Para cada transportadora

### Identificação
- [ ] nome da empresa;
- [ ] nome exato do app operacional;
- [ ] packageName;
- [ ] versionName;
- [ ] versionCode;
- [ ] targetSdk;
- [ ] data de atualização.

### Gravar uma baixa completa
- [ ] antes do scan;
- [ ] leitura do pacote;
- [ ] tela seguinte;
- [ ] recebedor;
- [ ] documento;
- [ ] assinatura;
- [ ] foto;
- [ ] confirmação;
- [ ] status final;
- [ ] sincronização.

### Código
- [ ] permite digitação manual?
- [ ] permite colar?
- [ ] exige scanner?
- [ ] permite múltiplos pacotes?

### Foto
- [ ] aceita galeria?
- [ ] exige câmera ao vivo?
- [ ] aparece no Compartilhar?
- [ ] aceita ACTION_SEND?
- [ ] mesma prova pode servir a múltiplos pacotes?

### Offline
- [ ] funciona sem internet?
- [ ] cria rascunho?
- [ ] onde ficam as pendências?
- [ ] existe envio posterior?
- [ ] como trata falha de sincronização?

### Integração
- [ ] possui portal web?
- [ ] possui API conhecida?
- [ ] possui deep link?
- [ ] existe Activity exportada útil?
- [ ] aceita extras de tracking?
- [ ] aceita texto?
- [ ] aceita imagem?

## Pergunta operacional principal

> O que precisa ser repetido quando existem vários pacotes para o mesmo local/recebedor?
