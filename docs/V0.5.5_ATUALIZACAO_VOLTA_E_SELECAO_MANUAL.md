# V0.5.5 — Atualização, Voltar e seleção manual

## Atualização do APK

1. Instale a V0.5.5 manualmente por cima da versão anterior. Esta é a primeira
   versão que contém o atualizador.
2. O Firebase Hosting no plano Spark não aceita APKs. Para cada versão futura,
   gere o piloto, publique o código/release GitHub, envie o APK para a Release
   e só então publique o manifesto no Firebase:
   `18_PREPARAR_PILOTO_V055` → `GITHUB\03_PUBLICAR_VERSAO` →
   `GITHUB\08_ENVIAR_APK_PARA_RELEASE` → `FIREBASE\03_SUBIR_ATUALIZACAO`.
3. O gerador cria `app-update.json` com a URL da Release GitHub baseada no
   remoto do projeto. O Firebase publica apenas o manifesto; o APK é baixado
   do GitHub quando o entregador toca em atualizar.
4. Ao abrir o Hub com internet, o aparelho recebe o aviso. O Android abre o
   download e pede autorização de instalação; sem rede, o Hub abre normalmente.

## Etiqueta sem padrão

1. Leia a etiqueta normalmente, por câmera, foto ou campo manual.
2. Se nenhuma regra corresponder, o Hub preserva o tracking e mostra iMile,
   Anjun e J&T para seleção.
3. A seleção recebe confiança `MEDIA`, regra `SELECAO_MANUAL` e exige revisão
   no registro criado; ela não ensina automaticamente uma nova regex ao app.
4. iMile segue para a pesquisa assistida já validada. Anjun e J&T permitem
   registrar o POD no Hub, mas não prometem uma baixa automática até que os
   respectivos aplicativos sejam homologados.

## Roteiro rápido de teste

1. Leia `60905264-49890` e confirme iMile + tracking `6090526449890`.
2. Leia `CODIGO-SEM-REGRA`, escolha J&T e confirme o aviso de seleção manual.
3. Inicie um POD, avance até assinatura e use o botão físico Voltar em cada
   etapa; dados já salvos devem permanecer intactos.
4. Com internet, altere temporariamente o manifesto para uma versão superior e
   confirme o botão de atualização. Em modo avião, confirme a abertura normal.
