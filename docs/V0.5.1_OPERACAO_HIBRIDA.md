# V0.5.1 — Operação híbrida

## Decisão operacional

O Delivery Hub identifica o contexto sem obrigar o entregador a escolher um modo:

- `CARGA_IMPORTADA`: o AWB pertence à carga atribuída; o progresso da carga é atualizado.
- `EXTRA_ROTA`: existe carga ativa, mas o AWB não está nela; a operação é permitida e marcada para conciliação.
- `SCANNER_LIVRE`: não existe carga ativa; a leitura é uma operação avulsa do dia.

## Verdades separadas

- O Delivery Hub é a fonte de verdade operacional e de auditoria.
- A transportadora é a fonte de verdade da baixa oficial.
- Uma prova salva no Hub nunca é convertida automaticamente em baixa confirmada.
