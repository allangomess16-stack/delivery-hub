# V0.2 — Fluxo operacional de entrega

## Implementado

- scanner por código digitado/colado como fallback de teste;
- busca somente dentro da carga do entregador selecionado;
- detecção de código duplicado;
- início e continuação de entrega;
- foto de etiqueta;
- foto de fachada/local;
- compressão das fotos no navegador;
- armazenamento das fotos em IndexedDB;
- seleção do recebedor;
- nome condicional para recebedor diferente de "próprio";
- confirmação física explícita;
- ocorrência "não entregue";
- motivos de não entrega;
- pausar e continuar depois;
- cancelar preparação;
- remoção das fotos ao cancelar;
- desfazer conclusão antes de baixa externa confirmada;
- histórico interno de eventos;
- resumo de pendentes, em andamento, entregues e não entregues.

## Limite proposital desta versão

O scanner nativo por câmera ainda não é a dependência principal da V0.2.

O campo de leitura está abstraído como entrada de tracking para validar o fluxo completo
sem bloquear o desenvolvimento por HTTPS/permissões do navegador.

No Android/Capacitor, o próximo passo é ligar o `NativeBridge` ao mesmo campo de entrada.

## Regra de segurança

A entrega física só muda para `ENTREGUE` quando o usuário toca explicitamente em:

```text
CONFIRMAR ENTREGA
```

Fotos, recebedor e preparação não concluem o pacote automaticamente.
