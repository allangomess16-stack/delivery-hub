# Decisoes de UX

- dark-first;
- contraste alto para uso de dia;
- botoes grandes;
- borda colorida de 2px nas acoes;
- cabecalho sempre fixo com contexto da operacao;
- rodape de acoes sempre fixo;
- fluxo operacional com no maximo duas decisoes principais por tela;
- campos desnecessarios nao aparecem;
- campos opcionais nao bloqueiam proximo;
- qualquer preparacao pode ser pausada ou cancelada;
- entrega fisica so termina com confirmacao explicita;
- falha externa nunca impede a proxima entrega;
- rolagem minima nas telas de rua;
- interface simples sem parecer sistema antigo ou pobre.
