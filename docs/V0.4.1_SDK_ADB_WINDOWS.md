# V0.4.1 — SDK/ADB local no Windows

## Problema observado

O download das Android Command Line Tools era concluído, mas `Expand-Archive` recebia `LiteralPath ''`. A causa era expansão antecipada de `%ZIP%` dentro de um bloco `IF (...)` no `cmd.exe`: a variável era definida dentro do bloco, mas `%ZIP%` tinha sido expandida antes da atribuição.

## Correção

- uso de `!ZIP!` e `!TMP!` com delayed expansion;
- validação de existência/tamanho do ZIP;
- limpeza segura de downloads temporários;
- validação de `sdkmanager.bat`;
- instalação de `platform-tools`, Android 35 e Build Tools 34.0.0;
- validação final de `adb.exe`;
- persistência dos caminhos em `.ferramentas/android-local.env`;
- `BAT/ANDROID/_COMUM_ANDROID.bat` procura primeiro o SDK local do próprio projeto.

## Fluxo

```text
BAT/APK/00_PREPARAR_SDK_ANDROID.bat
→ JDK 21
→ Command Line Tools
→ sdkmanager
→ platform-tools/adb.exe
→ BAT/ANDROID/02_DIAGNOSTICAR_APPS.bat
```

Nenhum desbloqueio de bootloader, root ou alteração OEM é necessário.
