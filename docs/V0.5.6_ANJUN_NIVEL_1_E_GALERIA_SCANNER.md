# V0.5.6 — Galeria no scanner e Anjun nível 1

## O que mudou

- O scanner ao vivo continua usando a câmera. O campo auxiliar, antes redundante,
  passou a abrir somente a **galeria** para ler uma etiqueta fotografada antes.
- A Anjun `com.anjun.supplierManagement` foi validada no aparelho apenas para o
  launcher, versão `2.4.0` / `versionCode 100`.
- Para tracking no formato `AJ` seguido de 14 ou 15 dígitos, o Hub copia o
  código e abre a Anjun. O entregador ainda localiza a busca, cola e conclui
  qualquer ação dentro do app da transportadora.
- Nenhuma baixa, prova, foto, assinatura, deep link ou Activity interna Anjun
  é automatizada nesta versão.

## Atualização do APK

No Windows, execute nesta ordem:

```text
BAT\FIREBASE\19_PREPARAR_PILOTO_V056.bat
BAT\GITHUB\03_PUBLICAR_VERSAO.bat
BAT\GITHUB\08_ENVIAR_APK_PARA_RELEASE.bat
BAT\FIREBASE\03_SUBIR_ATUALIZACAO.bat
```

O Firebase Hosting recebe apenas o manifesto. O APK deve estar anexado à
Release GitHub antes de publicar esse manifesto.

## Homologação segura da Anjun

1. Use uma etiqueta Anjun real, sem confirmar baixa.
2. Leia no Delivery Hub e confirme que a Anjun abre.
3. Cole manualmente na busca da Anjun e pare antes de qualquer confirmação.
4. Volte ao Hub pelo botão Android **Voltar**.
5. Execute `BAT\ANDROID\10_DIAGNOSTICAR_FLUXO_REAL_ANJUN.bat` e envie a pasta
   gerada em `diagnosticos-apk\anjun-real-*`.

Se a versão da Anjun não for exatamente `2.4.0` / `100`, o Hub não abre o app
automaticamente; esse bloqueio é intencional até a nova versão ser verificada.
