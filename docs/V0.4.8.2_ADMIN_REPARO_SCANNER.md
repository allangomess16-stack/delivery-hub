# V0.4.8.2 — Admin, reparo de cargas e colunas auxiliares

## Objetivo

Permitir que o administrador resolva rapidamente inconsistências de carga sem
duplicar pacotes, perder operações ou conhecer senhas dos entregadores.

## Distribuição de planilha

1. Importe o Excel normalmente.
2. Colunas conhecidas de numeração e a primeira coluna com sequência 1, 2, 3
   são descartadas automaticamente.
3. Para qualquer coluna auxiliar ainda exibida, use `IGNORAR COLUNA`.
4. Ao distribuir, cargas estruturais duplicadas são consolidadas somente se no
   máximo uma delas tiver operação iniciada.
5. Se duas cargas já tiverem entregas ou não-entregas, o sistema bloqueia e
   solicita revisão manual para preservar o histórico.

## Localizar uma etiqueta inconsistente

1. Entre como Admin e abra `Gestão de cargas`.
2. Use `LER FOTO DA ETIQUETA` ou digite o tracking em `BUSCAR TRACKING`.
3. Toque em `LOCALIZAR E ABRIR` quando usar a digitação.
4. O sistema abre a carga já filtrada no pacote encontrado.
5. Corrija endereço/região ou escolha o entregador de destino e use
   `TRANSFERIR`.

Se o mesmo tracking aparecer em mais de uma carga histórica, o sistema lista
as ocorrências e não escolhe silenciosamente uma delas.

## Redefinir senha

1. Abra `Gerenciar perfis` e selecione o entregador.
2. Toque em `ENVIAR REDEFINIÇÃO`.
3. O Firebase envia o link ao e-mail já cadastrado.

O Admin não visualiza a senha atual e não troca diretamente a credencial de
uma conta existente. Esse desenho mantém a trilha segura do Firebase Auth.

## Regressão mínima

- importar planilha com coluna `Nº`;
- ignorar uma coluna auxiliar manualmente;
- repetir a importação que antes acusava duas cargas ativas;
- buscar uma etiqueta por texto e por foto;
- transferir apenas um pacote pendente;
- enviar link de redefinição de senha;
- confirmar scanner, sincronização da Outbox e abertura da iMile.

## Preparação Android

O BAT `BAT\APK\00_PREPARAR_SDK_ANDROID.bat` procura primeiro um SDK completo em
outras versões extraídas na mesma pasta de Downloads. Se precisar instalar,
usa o Android CLI atual e valida fisicamente `adb.exe`, `android.jar` da API 35
e `aapt2.exe` do Build Tools 34.0.0 antes de declarar sucesso. Essa e a
versao padrao exigida pelo Android Gradle Plugin 8.7 usado no projeto.
Se o Android CLI não materializar esses dois pacotes, uma rotina isolada
consulta o catálogo oficial, valida tamanho/checksum dos arquivos e instala
somente os componentes ausentes.
