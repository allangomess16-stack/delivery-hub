# V0.5.8 — Formulário de comprovacao iMile

Este teste organiza no Delivery Hub os dados observados na baixa manual da iMile.

## Fluxo no Hub

1. Registre a etiqueta e, obrigatoriamente, a foto de comprovante de recebimento.
2. Escolha quem recebeu e informe nome completo, tipo/número do documento e, se necessário, notas.
3. Registre a assinatura do cliente. Para iMile ela é obrigatória.
4. Confirme o POD no Hub e use o botão para abrir a iMile.

## Limite desta versão

Os dados não são enviados automaticamente ao aplicativo iMile. A etapa posterior no aplicativo externo continua manual. A próxima investigação será identificar uma integração oficial, deep link com campos suportados ou outro mecanismo autorizado para reduzir esse preenchimento.
