# V0.2.8 — Hotfix do scanner ZXing

## Erro corrigido

O build da V0.2.7 falhava com:

```text
Property 'reset' does not exist on type 'BrowserMultiFormatReader'
```

A versão atual de `@zxing/browser` usada pelo projeto não expõe `reset()` em
`BrowserMultiFormatReader`.

## Correção

Foi removida a chamada:

```ts
leitor.reset();
```

A leitura de uma imagem isolada via:

```ts
decodeFromImageElement(...)
```

não depende dessa chamada.

A instância do leitor fica elegível para coleta de lixo ao fim da função.

## Resultado esperado

`npm run build` deve avançar além da etapa TypeScript do scanner.
